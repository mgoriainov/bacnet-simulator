Симулятор BACnet-устройств на Python для тестирования SCADA систем. Читает список точек из выгрузки, поднимает виртуальные устройства в сети, генерирует на них правдоподобные значения.
Обратите внимание, что формат файла для выгрузки точек и выгрузки пределов жестко определен, и находится в файлах репозитория.

Первым делом считываются данные из файла с точками, создается словарь, типа: {ID устройства: [(название точки, тип точки, ID точки, описание точки, категория точки), (...)]}.
Далее считываются диапазоны для заданных заранее типов: temp, power, current, voltage, energy, cos, pressure, other. В other попадают точки, неподходящие к другим типам.
После этого открывается соединение, для определения IP адреса компьютера.
Далее создаются устройства, для каждого свой порт (начиная с 47809). Для последующих устройств порт +1, +2 итд. Значения для точек этих устройств генерируются по синусоиде в заданных пределах с шумом.

Для запуска: установите зависимости из requirements.txt, в папку с программой добавить два CSV файла (с точками для создания и с пределами).
